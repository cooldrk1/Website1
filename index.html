О лабораторной работе

Цель — разместить статический сайт на своём компьютере с помощью Apache и открыть его с другого устройства в локальной сети.

  • HTML задаёт структуру страницы.
  • CSS оформляет страницу.
  • Apache передаёт файлы сайта браузеру по HTTP.

Проверка доступа

На компьютере с Apache откройте http://localhost. На другом устройстве в той же сети используйте http://<IP-компьютера>.
